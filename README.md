The official SPECS iconography as a Lens Studio package: every icon as a PNG, a packed icon atlas and the materials and scripts to place icons in a scene. UI Kit uses this package for its icons.

## What is inside

| Path | What it is |
|:--|:--|
| [`Icons/Assets/Icons.lspkg`](./Icons/Assets/Icons.lspkg/) | The package (version 4.0.0) |
| [`Icons/Assets/Icons.lspkg/Iconography`](./Icons/Assets/Icons.lspkg/Iconography/) | Every icon as a PNG, grouped by category |
| [`Icons/Assets/Icons.lspkg/IconAtlas`](./Icons/Assets/Icons.lspkg/IconAtlas/) | All icons packed into one texture |
| [`Icons/Icons.esproj`](./Icons/) | Lens Studio project that contains the package |

## Getting Started

The simplest way to use the icons is to install **Icons** from the **Asset Library** in Lens Studio 5.25.0 or later. Use this repository to browse the icons or open the package as a project.

```bash
git clone https://github.com/specs-devs/icons.git
```

Then open `Icons/Icons.esproj` in Lens Studio. The package ships its own [`README.md`](./Icons/Assets/Icons.lspkg/README.md) with usage notes.
